# Дневник чтения (Reading Diary)

REST API для ведения дневника прочитанных книг на Go.

## Технологический стек

- **Backend**: Go с фреймворком Gin
- **База данных**: PostgreSQL с драйвером pgx
- **Аутентификация**: Нет (можно добавить JWT)
- **Конфигурация**: Environment variables (.env)

## Основные сущности

### Пользователь (User)
- ID (UUID)
- Имя
- Email (уникальный)

### Книга (Book)
- ID (UUID)
- UserID (внешний ключ)
- Название
- Описание
- Рейтинг (0-5)
- Статус чтения

## Функциональность

### Управление пользователями
- Регистрация новых пользователей
- Просмотр всех пользователей
- Поиск пользователя по ID
- Удаление пользователя с каскадным удалением книг

### Управление книгами
- Добавление книг к пользователю
- Просмотр книг пользователя
- Обновление статуса чтения
- Изменение рейтинга
- Удаление книг

### Статусы книг
- "want" - запланировано к прочтению
- "reading" - в процессе чтения  
- "finished" - прочитано
