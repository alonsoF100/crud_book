# Дневник чтения (Reading Diary)

REST API для ведения дневника прочитанных книг на Go.

## Возможности

- Управление пользователями
- Добавление книг с рейтингом и статусом
- Отслеживание прогресса чтения
- Полноценное CRUD API

## API Endpoints

### Пользователи
- `POST /users` - создать пользователя
- `GET /users` - получить всех пользователей
- `GET /users/:id` - получить пользователя по ID
- `DELETE /users/:id` - удалить пользователя (каскадно)

### Книги
- `POST /books` - добавить книгу
- `GET /books/:id` - получить книгу по ID
- `PUT /books/:id/status` - обновить статус книги
- `PUT /books/:id/rating` - обновить рейтинг книги
- `DELETE /books/:id` - удалить книгу
- `GET /users/:id/books` - получить книги пользователя

## Технологии

- Go (чистый net/http)
- In-memory хранилище с sync.RWMutex
- UUID для идентификаторов
- JSON для API
